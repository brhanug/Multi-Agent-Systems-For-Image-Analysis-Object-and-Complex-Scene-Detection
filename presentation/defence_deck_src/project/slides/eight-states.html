WHY EXACTLY 8

A-object: 4 values × A-scene: 2 values = 8

A-vlm adds nothing: it is 1 whenever A-object is above 0. A-agree follows from both.

Every picture in a row gets the same decision and the same uncertainty. 1,208 + 195 + … + 4,154 = 12,110.

Part 2 of 5 · The first design and why it failed

Where do the eight rows come from? A-object can take four values — 0, a third, two thirds, 1 — and A-scene only two, 0.5 or 1. Four times two is eight. A-vlm cannot make more combinations, because it is always 1 when A-object is above zero and 0 when it is zero. A-agree is computed from those two. So each of the 12,110 pictures falls into one of these eight rows; the right column shows how many. All pictures in the same row get exactly the same decision and exactly the same uncertainty, so the system cannot tell them apart. That is the core weakness of the old design.
