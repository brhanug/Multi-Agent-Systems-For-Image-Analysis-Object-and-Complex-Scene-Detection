Part 3 of 5 · The corrected design

Step two: the three agents. The object finder is the retrained detector; for each of the eight classes it reports its best box score, and it also gives the boxes. The scene matcher, SigLIP, compares the picture with one sentence per scene class and with “not a scene” sentences; it reports five scene scores plus the best “not a scene” score. Important: it scores each sentence on its own with a sigmoid, so it can say that no sentence fits; the old version used a forced choice that always picked a scene. The describer, LLaVA, is asked one yes/no question per class — five scene classes and eight object classes — and I read how strongly it leans towards “yes” from its probabilities for the first word. That gives 27 numbers per picture. The yes/no questions are only how the describer is read; the decision between classes uses all numbers together.
