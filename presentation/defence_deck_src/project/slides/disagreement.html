Part 4 of 5 · Results

Now the question the system was built on: does disagreement between the models warn us when an answer is wrong? I wrote the test down before running it, on 19 September. On the 300 hand-annotated pictures, disagreement over the object classes ranks the errors of the scene call with an AUROC of 0.378; the system’s own confidence ranks the same errors at 0.825. By the rule I fixed, the answer is no. But that test asked object disagreement about scene errors — two different tasks — so its below-chance value says more about the mismatch than about disagreement. Measured within each task, disagreement does carry information: 0.78 for object labels and 0.82 for scene presence. It is still never better than confidence: 0.84 and 0.83. So the answer stays no — disagreement adds nothing over confidence. The reason is that the errors are not where the models disagree — they are where all of them are wrong together: on 149 of 199 errors, all three agents make the same mistake. Disagreement cannot see an error that everyone shares.
