Part 4 of 5 · Results

My advisors asked: compared with what? There is no published system for this archive and these classes, so I re-ran four baselines myself, all on the same pictures, labels and 200 splits, with the plan written before running them. Each answers one question. The old system, as it was deployed, asks whether the work improved on what existed. The linear probe is the standard way to use one frozen foundation model: SigLIP turns each picture into 1,152 numbers and a logistic regression is trained on them; it asks whether several agents beat one model. The describer alone, with the same learned mapping and cut-off, is the strongest single agent; it asks whether combining agents adds anything. And zero-shot — SigLIP’s best-matching sentence or LLaVA’s strongest yes, with no training — asks what the models give for free.
