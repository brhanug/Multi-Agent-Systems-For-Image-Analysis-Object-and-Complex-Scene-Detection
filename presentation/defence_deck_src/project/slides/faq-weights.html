Backup A

If asked about the weights: every hand-set weight was also learned. In the old design, the signals take only eight states, so any weighting can only produce six different rules, and 0.6/0.2/0.2 is already the best of them. The routing weight 0.6/0.4 gives identical decisions for any weight from 0 to 0.6. Learning every variable of the old design at once still leaves it 12.6 points behind. In the corrected design, for scene at all, learned and fixed weights give the same result, so I kept the fixed ones because the archive tests were fixed with them. For the scene classes, learning is clearly better, so the system learns them — and when the choice itself is made inside each split, on training books only, the learned mapping wins 196 of 200 times. For objects, learning does not help.
