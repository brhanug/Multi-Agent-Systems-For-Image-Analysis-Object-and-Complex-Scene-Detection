Deciding one picture

INPUT: a scan; the weights (Alg. 1); the cut-offs λ̂ (Alg. 3)

1 restore the scan; run the three agents → 27 numbers

2 each agent: p = 1 ÷ (1 + e−(bias + weights · numbers))

3 scene at all: p = 0.6·p₁ + 0.2·p₂ + 0.2·p₃; u = 1 − |p − 0.5|

if u < λ̂ approve, else a person

4 scene class: 6 probabilities from all 27 numbers; answer = largest

u = 1 − largest; if u < λ̂-class approve, else a person + short list

5 objects: per class, average of 3 probabilities; list = classes ≥ t

OUTPUT: three answers, each approved or routed to a person

In one sentence: turn the agents’ numbers into three answers, and let each answer through only if it is sure enough.

THE EXAMPLE

p = 0.97, u = 0.53 < 0.829 → approved

class family 0.54, u = 0.46 > 0.26 → a person

objects ≥ 0.088 → person, child, animal

Part 3 of 5 · The corrected design · the algorithms

Algorithm two runs for every picture and learns nothing. Restore the scan and run the three agents. For each agent, put its numbers into its learned formula to get a probability. For “scene at all”, take the weighted average of the three probabilities, measure how far it is from 0.5, and approve if the uncertainty is below the cut-off. For the scene class, compute the six class probabilities from all 27 numbers, pick the largest, and approve only if the largest is high enough; otherwise a person gets a short list. For objects, average the three agents’ probabilities per class and list the classes above the threshold for a person to confirm. For the example: the scene call is approved, the class goes to a person, and the object list is person, child and animal.
