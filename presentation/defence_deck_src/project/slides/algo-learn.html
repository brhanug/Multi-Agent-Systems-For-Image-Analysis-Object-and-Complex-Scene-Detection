Algorithm 1 · done once, on the training books

Learning the mappings

INPUT: training pictures with a human label; each agent’s numbers for them

1 for each agent (object finder, scene matcher, describer):

2 collect its numbers for every training picture

3 fit a logistic regression: label ← its numbers

4 keep the bias and one weight per number

5 scene class: one regression on all 27 numbers → 6 answers

6 objects: per class, one regression per agent

OUTPUT: the weights, used for every picture afterwards

In one sentence: the system learns from labelled examples how much each number is evidence for each answer.

Part 3 of 5 · The corrected design · the algorithms

Algorithm one is done once, before the system is used, on the training books only. For each agent, collect its numbers for every training picture and fit a logistic regression that predicts the human label from those numbers. What we keep is a bias and one weight per number. For the scene class there is one regression on all 27 numbers with six possible answers; for objects, one small regression per class and agent. In one sentence: the system learns from labelled examples how much each number counts as evidence. On the right are the real learned weights of the object finder for “is there a scene”: a person counts strongly for a scene, an animal too, and text slightly against. Nobody set these numbers by hand.
