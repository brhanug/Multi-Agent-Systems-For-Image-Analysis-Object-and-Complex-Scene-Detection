Part 3 of 5 · The corrected design

This diagram shows how everything fits together. There are two lanes. On the left, the work done once, before the system is used: the labelled books are split. Training books go into Algorithm 1, which learns the mappings — the weights. Calibration books go into Algorithm 3, which chooses the cut-offs, lambda-hat. Test books are only used to measure. On the right, what happens to every single picture, Algorithm 2: restore it, run the three agents side by side, map their numbers to probabilities using the learned weights, form the three answers and their uncertainty, and compare with the cut-off — approve, give a short list, or send to a person. Everything in blue is learned once and reused; nothing is learned while a picture is processed, and the agents never talk to each other. The next three slides show the three algorithms.
